# FINE ATLAS ♓ 江坂20km圏内「お魚カスタム定期便」営業図鑑 ＆ 仕入・配送戦略（Pisces Field & Procurement Edition v2.0）

株式会社ファインアトラス（ファインスタッフ × 対馬水産）の**「お魚カスタム定期便（月額1万円〜：煮穴子・穴子フィレ・甘鯛・のどぐろ・剣先イカ ＋ 拡張冷凍5品目）」**向け、江坂駅半径20km圏内の**厳選60店舗（Sランク30店・Aランク30店）営業攻略コンパス**、および**全国業務用冷凍魚10品目の仕入れ価格AI調査・江坂拠点配送モデル損益シミュレーター**です。

## 収録コンテンツ

1. **インタラクティブ営業図鑑 ＆ 仕入・配送シミュレーター Webサイト（`index.html`）**
   - **モード①：🎯 江坂20km 営業図鑑（厳選60店舗）**
     - 主力5商材（煮穴子・穴子フィレ・甘鯛・のどぐろ・剣先イカ）別の目利き解説＆ワンタップ絞り込み
     - 勝ち筋3大ターゲット層・4エリア・課題シグナル（ワンオペ／SNS活発／市場遠方／現在架電ゴールデンタイム🟢）フィルター
     - 全60店舗の実在・電話番号・SNS/口コミ裏取り根拠、月額1万円カスタム定期便レシピ、二段構え営業トークの1タップコピー
     - ブラウザ自動保存（既存 `localStorage` 完全互換）の架電ステータス・富田君メモ管理＆CSV出力
     - 江坂駅中心・半径20kmインタラクティブ海図（全60店舗プロット）＆関西の料理長「断り文句」切り返し図鑑
   - **モード②：📊 全国冷凍魚 仕入AI調査 ＆ 江坂配送モデル試算**
     - 全国業務用冷凍魚10品目（主力5品目＋大阪アップセル拡張5品目）の卸売相場レンジ・歩留まり・1皿実質原価・飲食店原価率（26.5〜30.2%）一覧
     - 凍結技術別（一般緩慢冷凍 vs 高真空急速 vs プロトン/CAS/液体凍結『凍眠』）ドリップ流出率・品質比較
     - 江坂拠点・半径20km配送3モデル（①ヤマトクール便単独／②自社軽バン冷凍車単独／③ハイブリッド段階移行）リアルタイム損益シミュレーター＆曜日別4クラスター巡回計画
2. **5シート構成 統合Excelブック（`2_江坂20km圏内_営業リスト_ファインアトラス定期便.xlsx`）**
   - `ダッシュボード_江坂20km戦略`（全60店舗連動の自動集計関数・グラフ・3大ターゲット戦略解説）
   - `江坂20km_S・A厳選架電リスト`（全60店舗のSNS/口コミ根拠・加工度レシピ・トークスクリプト・進捗プルダウン）
   - `関西版_商材別_切り返しトーク設計書`（全6パターンの反論処理スクリプト）
   - `全国冷凍魚10品目_仕入相場AI調査`（10品目の卸相場・FA粗利率計算式・1皿原価＆FL率計算式・凍結技術比較）
   - `江坂20km_配送モデル損益試算`（配送3モデルの単店損益・15/23/39/60店舗フェーズ別損益計算式・曜日別巡回ルート表）
3. **経営検討レポート（`docs/全国冷凍魚_仕入価格AI調査_江坂配送モデル検討書.md`）**
   - 社長・尾崎さん・富田君向けの結論サマリー、10品目相場＆FL原価表、配送3モデル損益分岐点分析、60店舗展開ロードマップ
